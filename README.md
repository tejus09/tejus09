## 🚀 Featured Projects

### 🎯 Multi-Object Tracking from Scratch (toy-bytetrack)

**[Repo →](https://github.com/tejus09/toy-bytetrack)**

Implemented **ByteTrack** multi-object tracking from scratch — Kalman Filter state estimation, Hungarian algorithm for data association, integrated with YOLOv8 detection. Includes gradient trail visualisation and robust video output. Built to internalise the algorithm rather than wrap a library.

`Python` `YOLOv8` `ByteTrack` `Kalman Filter` `OpenCV`

---

### 🚦 Real-Time Traffic Congestion Analyzer

**[Repo →](https://github.com/tejus09/traffic-congestion-analyzer)**

Production-style congestion monitoring using **pixel-occupancy masking** (measures road area occupied, not just vehicle count) with temporal smoothing to prevent state flickering. Features an interactive CLI region-of-interest (ROI) drawer for arbitrary camera setups.

`Python` `YOLOv8` `OpenCV` `Temporal Smoothing`
